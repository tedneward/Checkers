# Checkers
A head-to-head version of the classic game.

Features:

- For two players (no AI player!)
- AI assistance for those new to the game.
- Clean, simple design
- Rules available for review
- Game history stored for replay value

Game options:

- Use either the British or American Rules

The app is USD$0.99, with no ads and no in-app purchases. Buy it once, play it forever!
