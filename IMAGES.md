# Image Generation Prompts

## Icon Suggestions (for generating app icons)

These prompts are designed for use with Stability Matrix to generate clean, flat icons for a classic checkers app.

### 1. Minimal Flat Design
```
Create a flat, minimalist checkers app icon. Show an 8x8 checkered board with alternating dark red and light cream squares, viewed from above. Place a single red man on a dark red square and a black king on another square to show piece variety. Use high contrast, bold outlines, no shadows, no gradients, no decorative borders, no text, no logo. Output square format, suitable for mobile app icon.
```

### 2. Classic Board Close-up
```
Generate a square app icon featuring a close-up of a classic American checkers board. Alternate red and white squares. Show a red checker piece and a black checker piece (man and king) on the board. Keep geometric shapes, solid colors, minimal details. Avoid 3D perspective, drop shadows, bevels, or lighting effects. Clean, modern, vector-like.
```

### 3. Monochromatic Symbol
```
Design a monochromatic checkers symbol for an app icon. Use bold geometric shapes: two red squares and two black squares forming a minimal checkerboard fragment. Include a circular red man and a crowned black piece. Flat design with no gradients, no textures, no text. High contrast for small sizes.
```

### 4. Modern Gradient-Free Logo
```
Create a modern checkers app icon. Top-down view of an 8x8 checkered pattern in deep red and ivory. Position a red man on d6 and a black king on d3 to show the two sides. No shading, no embossed look, no drop shadows, no outlines decoration. Use solid fills only. Minimal and recognizable at 48x48.
```

### 5. Bold Two-Color Icon
```
Generate a bold two-color app icon for Checkers. Split or show a minimal checkerboard: use red (#D62828) and white (#FFFFFF) as the primary colors, black (#1A1A1A) for pieces. Show exactly one red man and one black king. Flat, sans-serif, no text, no frame. Designed for iOS/Android app launcher.
```

### 6. Simplified Symbol
```
Create a highly simplified checkers icon. Abstract 4x4 checkerboard in the corner, with a red checker on top-left and black checker below it. Focus on piece shapes: round men, round king with a small crown. No board border, no numbers, no text. Flat design optimized for small app icon sizes.
```

## Splash Screen Suggestions (for generating splash screens)

These prompts are designed for use with Stability Matrix to generate full-screen splash screens.

### 1. Clean Centered Design
```
Create a full-screen splash screen for a Checkers mobile app. Centered on a light cream background (#FDF6E3), display a simplified 8x8 checkered board with red and cream squares. Place a red man and a black king on adjacent squares. Use generous whitespace, minimal typography. No app title text required, just the visual mark. Flat, modern, no 3D, no shadows.
```

### 2. Minimal Branding Splash
```
Generate a minimalist splash screen. White background. Large centered checkers symbol: top-down checkerboard fragment with red and black pieces. Subtle, elegant, loads quickly. No gradients, no decorative elements, no tagline, no company name. Suitable for 1080x1920 and 1242x2688 resolutions.
```

### 3. Classic American Checkers Theme
```
Design a splash screen showing a classic American checkers setup. Soft ivory background. Centered full checkerboard with deep red and ivory squares. Show opening position glimpse with red and black pieces. Keep pieces as flat circles; kings marked with a simple crown. Avoid perspective skewing. Clean, timeless aesthetic.
```

### 4. Dark Mode Friendly
```
Create a dark-themed splash screen for Checkers. Charcoal background (#1E1E1E), with a centered checkerboard in muted red (#8B2635) and cream (#F4EDE8). Two pieces visible: red man and black king. High contrast, minimal, modern. No text, no logo branding, no animations. Flat design.
```

### 5. Bold Hero Splash
```
Generate a bold hero splash screen. Cream background. Centered checkerboard taking up ~40% of screen width. Dramatic use of solid red and black pieces to create visual interest. Clean layout with plenty of breathing room. No tagline, no version number, no buttons. Purely decorative mark for app launch.
```

### 6. Playful Minimal
```
Create a playful yet minimal splash screen. Very light background with a centered abstract checkers pattern: a partial board showing a jump scenario (red man jumping black man conceptually). Use simple geometric shapes. Avoid complex lighting, textures, or illustrations. Focus on clarity and speed. Works well on both light and dark displays.
```
